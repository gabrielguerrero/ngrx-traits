# Pagination: withEntitiesLocalPagination, withEntitiesRemotePagination, withEntitiesRemoteScrollPagination

`[collection]EntitiesCurrentPage` is a **DeepSignal**: read each prop as its own signal
(`store.productEntitiesCurrentPage.entities()`), not `store.productEntitiesCurrentPage().entities()`.

## withEntitiesLocalPagination

Pages an already loaded list in memory. Requires `withEntities`.

```typescript
withEntitiesLocalPagination(productEntityConfig, { pageSize: 10 });
```

| Option | Description | Default |
|---|---|---|
| `pageSize` | Entities per page | required |
| `currentPage` | Initial page index | `0` |

```typescript
productEntitiesPagination: Signal<{ currentPage: number; pageSize: number }>;
productEntitiesCurrentPage: DeepSignal<{
  entities: Product[]; pageIndex: number; total: number; pageSize: number;
  pagesCount: number; hasPrevious: boolean; hasNext: boolean;
}>;
loadProductEntitiesPage({ pageIndex, pageSize? }): void;
```

## withEntitiesRemotePagination

Pages from the backend and keeps `pagesToCache` pages in memory. Changing page calls
`setProductEntitiesLoading()`, so `withEntitiesLoadingCall` fetches with `productEntitiesPagedRequest()`.
Requires `withEntities` + `withCallStatus`.

```typescript
withEntitiesRemotePagination(productEntityConfig, { pageSize: 10, pagesToCache: 2 });
```

| Option | Description | Default |
|---|---|---|
| `pageSize` | Entities per page | required |
| `pagesToCache` | Pages kept in memory | `3` |
| `currentPage` | Initial page index | `0` |

```typescript
productEntitiesPagination: Signal<{
  currentPage: number; requestPage: number; pageSize: number; total: number;
  pagesToCache: number; cache: { start: number; end: number };
}>;
productEntitiesCurrentPage: DeepSignal<{
  entities: Product[]; pageIndex: number; total: number; pageSize: number;
  pagesCount: number; hasPrevious: boolean; hasNext: boolean; isLoading: boolean;
}>;
productEntitiesPagedRequest: DeepSignal<{ startIndex: number; size: number; page: number }>;
loadProductEntitiesPage({ pageIndex, pageSize?, forceLoad?, skipLoadingCall? }): void;
setProductEntitiesPagedResult({ entities, total }): void; // only when fetching manually
```

`fetchEntities` must return `{ entities, total }` — `total` drives the paginator.
The entity collection only holds the cached window, so render from
`productEntitiesCurrentPage.entities()` and never combine this with a local filter or sort.

```html
@for (product of store.productEntitiesCurrentPage.entities(); track product.id) { ... }
<mat-paginator
  [length]="store.productEntitiesCurrentPage.total()"
  [pageSize]="store.productEntitiesCurrentPage.pageSize()"
  [pageIndex]="store.productEntitiesCurrentPage.pageIndex()"
  (page)="store.loadProductEntitiesPage($event)"
/>
```

## withEntitiesRemoteScrollPagination

Infinite scroll: the cache keeps growing instead of dropping old pages. Also fits next/previous paging
when the total is unknown. Requires `withEntities` + `withCallStatus`.

```typescript
withEntitiesRemoteScrollPagination(productEntityConfig, { pageSize: 20, pagesToCache: 3 });
```

```typescript
loadMoreProductEntities(): void;
loadProductEntitiesNextPage(): void;
loadProductEntitiesPreviousPage(): void;
loadProductEntitiesFirstPage(): void;
setProductEntitiesPagedResult({ entities, total?, hasMore? }): void;
```

`fetchEntities` can return `{ entities }` (no more results when fewer than the requested size come back),
`{ entities, total }`, or `{ entities, hasMore }`.

```typescript
// component
store = inject(ProductsScrollStore);
dataSource = getInfiniteScrollDataSource(this.store, { collection: 'product' });
```

```html
<cdk-virtual-scroll-viewport itemSize="42" minBufferPx="200" maxBufferPx="200">
  <mat-list>
    <mat-list-item *cdkVirtualFor="let item of dataSource; trackBy: trackByFn">{{ item.name }}</mat-list-item>
  </mat-list>
</cdk-virtual-scroll-viewport>
```

## With the resource view

There is no resource per page. Take `status()` and `error()` from the resource generated by
[`withEntitiesLoadingCall`](entities-loading.md), and the rows, total and page index from
`productEntitiesCurrentPage`.
