# ngrx-traits Skill

Helps users of `@ngrx-traits/signals` compose signal stores correctly.

## When invoked

- If the user references existing files (services, models, stores), read them first.
- Otherwise work standalone using the patterns below and the resource files.

## Composition ordering rules

Order matters. Traits that read signals must come after the traits that generate them.

### Strict ordering (must follow)

1. `withEntities` — always first for entity stores
2. `withCallStatus` — must come before all other `withEntities*` traits
3. `withAllCallStatus` — must be before `withCalls` / `withCallStatus` / `withEntitiesCalls` it monitors
4. `withEntitiesMultiSelection` / `withEntitiesSingleSelection` — after `withEntities`
5. Remote filter/pagination/sort (`withEntitiesRemote*`) — after `withCallStatus`
6. Local filter/pagination/sort (`withEntitiesLocal*`) — after `withEntities`
7. `withSyncToWebStorage` / `withServerStateTransfer` — after state features, **before** loading calls
8. `withEntitiesSyncToRouteQueryParams` — after all remote filter/sort/pagination features, before loading call
9. `withEntitiesLoadingCall` — **last** among entity traits (reads signals from all above)
10. `withCalls` — after any state it references via factory param
11. `withLogger` — last (development only)

### Key rule of thumb

> If trait B reads a signal generated by trait A, B must come after A.

## Golden path recipes

### 1. Local pagination + filter + sort (data loaded once from server)

```typescript
// entityConfig defines entity type and optional collection name
const cfg = entityConfig({ entity: type<Product>(), collection: 'product' });

export const ProductsLocalStore = signalStore(
  { providedIn: 'root' },
  withEntities(cfg),
  withCallStatus({ ...cfg, initialValue: 'loading' }),
  withEntitiesLocalPagination({ ...cfg, pageSize: 10 }),
  withEntitiesLocalFilter({
    ...cfg,
    defaultFilter: { search: '' },
    filterFn: (entity, filter) =>
      !filter?.search || entity.name.toLowerCase().includes(filter.search.toLowerCase()),
  }),
  withEntitiesLocalSort({ ...cfg, defaultSort: { field: 'name', direction: 'asc' } }),
  withEntitiesSingleSelection(cfg),         // optional
  withEntitiesLoadingCall({
    ...cfg,
    fetchEntities: () => inject(ProductService).getProducts().pipe(map(d => d.resultList)),
  }),
);
```

Template signals: `store.productEntitiesCurrentPage()`, `store.productEntitiesFilter()`, `store.productEntitiesSort()`
Methods: `store.loadProductEntitiesPage({pageIndex})`, `store.filterProductEntities({filter})`, `store.sortProductEntities({sort})`

### 2. Remote pagination + filter + sort (server handles all)

```typescript
const cfg = entityConfig({ entity: type<Product>(), collection: 'product' });

export const ProductsRemoteStore = signalStore(
  { providedIn: 'root' },
  withEntities(cfg),
  withCallStatus({ ...cfg, initialValue: 'loading' }),
  withEntitiesRemoteFilter({ ...cfg, defaultFilter: { search: '' } }),
  withEntitiesRemotePagination({ ...cfg, pageSize: 10, pagesToCache: 2 }),
  withEntitiesRemoteSort({ ...cfg, defaultSort: { field: 'name', direction: 'asc' } }),
  withEntitiesSyncToRouteQueryParams(cfg),  // optional URL sync
  withEntitiesLoadingCall(
    ({ productEntitiesFilter, productEntitiesPagedRequest, productEntitiesSort }) => ({
      ...cfg,
      fetchEntities: async () => {
        const res = await lastValueFrom(
          inject(ProductService).getProducts({
            search: productEntitiesFilter().search,
            skip: productEntitiesPagedRequest().startIndex,
            take: productEntitiesPagedRequest().size,
            sortColumn: productEntitiesSort().field,
            sortAscending: productEntitiesSort().direction === 'asc',
          }),
        );
        return { entities: res.resultList, total: res.total };
      },
    }),
  ),
);
```

### 3. Infinite scroll (remote scroll pagination)

```typescript
const cfg = entityConfig({ entity: type<Product>(), collection: 'product' });

export const ProductsScrollStore = signalStore(
  { providedIn: 'root' },
  withEntities(cfg),
  withCallStatus({ ...cfg, initialValue: 'loading' }),
  withEntitiesRemoteFilter({ ...cfg, defaultFilter: { search: '' } }),
  withEntitiesRemoteScrollPagination({ ...cfg, pageSize: 20, pagesToCache: 3 }),
  withEntitiesLoadingCall(
    ({ productEntitiesFilter, productEntitiesPagedRequest }) => ({
      ...cfg,
      fetchEntities: async () => {
        const res = await lastValueFrom(
          inject(ProductService).getProducts({
            search: productEntitiesFilter().search,
            skip: productEntitiesPagedRequest().startIndex,
            take: productEntitiesPagedRequest().size,
          }),
        );
        return { entities: res.resultList, total: res.total };
      },
    }),
  ),
);
// Component: dataSource = getInfiniteScrollDataSource(store, { collection: 'product' })
```

### 4. withCalls — single call with result + reactive callWith

```typescript
export const ProductDetailStore = signalStore(
  withEntities(cfg),
  withEntitiesSingleSelection(cfg),
  withEntitiesLoadingCall({ ...cfg, fetchEntities: () => inject(ProductService).getProducts().pipe(map(d => d.resultList)) }),
  withCalls(({ productEntitySelected }) => ({
    loadProductDetail: callConfig({
      call: ({ id }: { id: string }) => inject(ProductService).getProductDetail(id),
      resultProp: 'productDetail',
      callWith: productEntitySelected, // auto-calls when selection changes
    }),
  })),
);
// store.productDetail() — result signal
// store.isLoadProductDetailLoading() / isLoadProductDetailLoaded()
```

### 5. withCalls — await result in component

```typescript
// Store
withCalls(() => ({
  registerUser: callConfig({
    call: (params: { name: string; email: string }) => inject(UserService).register(params),
    mapError: (error) => (error as HttpErrorResponse).error.message,
  }),
}))

// Component
async onSubmit() {
  const result = await this.store.registerUser({ name, email });
  if (result.ok) {
    this.snackBar.open('Success!', 'Close');
  } else {
    this.snackBar.open(result.error() as string, 'Close');
  }
}
```

### 6. Per-entity calls (withEntitiesCalls)

```typescript
// For parallel per-row actions (expand row, mutate status, delete)
withEntitiesCalls({
  ...orderCfg,
  calls: (store, svc = inject(OrderService)) => ({
    loadOrderDetail: (entity: OrderSummary) =>
      svc.getOrderDetail(entity.id).pipe(map(({ items }) => ({ items }))),
    // return Partial<Entity> to update, undefined to delete
  }),
})
// store.isLoadOrderDetailLoading(order) — per-entity status
```

### 7. Split store with ExtractStoreFeatureOutput

```typescript
// feature-a.ts
export function withProductEntities() {
  return signalStoreFeature(
    withEntities(cfg), withCallStatus({ ...cfg, initialValue: 'loading' }),
    withEntitiesRemoteFilter({ ...cfg, defaultFilter: { search: '' } }),
    // ... more traits
  );
}
export type ProductEntitiesOutput = ExtractStoreFeatureOutput<typeof withProductEntities>;

// feature-b.ts (depends on feature-a output)
export function withProductCalls() {
  return signalStoreFeature(
    type<ProductEntitiesOutput>(), // declares dependency
    withEntitiesLoadingCall(({ productEntitiesFilter }) => ({
      ...cfg,
      fetchEntities: async () => { /* ... */ },
    })),
  );
}

// store.ts
export const ProductStore = signalStore(withProductEntities(), withProductCalls());
```

### 8. SSR state transfer

```typescript
signalStore(
  withEntities(cfg),
  withCallStatus({ ...cfg, initialValue: 'loading' }),
  // ... feature traits ...
  withServerStateTransfer({ key: 'my-state' }), // BEFORE loading call
  withEntitiesLoadingCall({ ...cfg, fetchEntities: () => inject(Service).getProducts() }),
)
```

### 9. Web storage persistence

```typescript
signalStore(
  withEntities(cfg),
  withCallStatus({ ...cfg, initialValue: 'loading' }),
  withSyncToWebStorage({ key: 'my-cache', type: 'session', expires: 1000 * 60 * 60 * 12 }),
  withEntitiesLoadingCall({ ...cfg, fetchEntities: () => inject(Service).getProducts() }),
)
```

## Naming conventions (collection = 'product')

| Generated item | Name pattern |
|---|---|
| entities array | `productEntities()` |
| call status | `isProductEntitiesLoading()`, `isProductEntitiesLoaded()`, `productEntitiesError()` |
| filter | `productEntitiesFilter()`, `filterProductEntities({filter})` |
| sort | `productEntitiesSort()`, `sortProductEntities({sort})` |
| current page | `productEntitiesCurrentPage()` |
| paged request | `productEntitiesPagedRequest()` |
| single selection | `productEntitySelected()`, `selectProductEntity({id})` |
| multi selection | `productIdsSelectedMap()`, `toggleSelectProductEntities({id})` |

Without collection, names use `entities` / `entitiesCurrentPage` etc.

## Testing quirks

- `inject()` inside `withCalls` / `withEntitiesLoadingCall` factories works in tests via `TestBed.runInInjectionContext` or normal `TestBed` setup.
- Provide the store with `TestBed.configureTestingModule({ providers: [MyStore] })` — do not call `new MyStore()`.
- To trigger loading in tests: call `patchState(store, { productEntitiesCallStatus: 'loading' })` if you don't want `initialValue: 'loading'`.
